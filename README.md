# PII-guard

Поднимите сервис командой `docker compose up --build` (Redis + Go-сервер на порту 8080). Отправляйте запросы на `POST /process` с телом `{"payload": "...", "payload_id": "..."}` — первый запрос с новым `payload_id` маскирует ПД, повторный с тем же `payload_id` и нашим `result` демаскирует. Управление политиками систем — через `POST/GET /systems`, метрики — `GET /stats`, готовность — `GET /app/health`. Настройка через env: `REDIS_URL`, `PII_RPS_TARGET`, `PII_APP_PORT`, `PII_STORE_KEY`. Значения персональных данных не логируются и не попадают в метрики.
